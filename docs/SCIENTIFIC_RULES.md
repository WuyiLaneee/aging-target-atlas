# 科研收录与图谱表达规则

版本 1.1.0，2026-10-19。全文规则源于用户确认需求；本文件是维护用约束，不是临床或产品功效指南。

1. **入库单位**：具体基因/蛋白、家族、复合物、通路、过程、表型、干预物分别建档。核心统计只包含具有合格功能依据的条目；辅助复合物不计核心基因数。
2. **研究范围**：人类和其他哺乳动物的实际实验。混合物种论文只提取合格部分；不由数据库 human 标签推断全部实验来自人体。
3. **核心依据**：至少一篇核对过的原始功能研究；对靶点有遗传干预，或机制匹配且有依据的药理干预，并处于明确衰老研究情境，有匹配结果。纯表达、组学富集、相关性、对接、网络药理学不满足核心条件。
4. **主张对应实验**：记录模型、实际实体、组织细胞、干预、终点、条件、局限与定位。下游变化、靶点依赖、直接结合分别解释；药理研究不自动证明特异性、必要性或充分性。
5. **机制读出**：表达、蛋白丰度、磷酸化位点与酶活分别记录。例如 ATM 对 SIRT6 Ser112 的磷酸化/稳定性不能简化为无条件提高 SIRT6 去乙酰化活性。
6. **表型层次**：细胞衰老、分泌表型、损伤保护、组织年龄功能、健康寿命和寿命分开。减少 SASP 不等于逆转全部细胞衰老；干细胞再建不等于整鼠延寿。
7. **皮肤维度**：直接皮肤衰老、皮肤相关损伤、其他组织和尚未评估分别标记。单次急性 UV 损伤不自动满足核心收录；正常原代、永生化、肿瘤细胞、组织、动物、人体分开。
8. **材料/药物**：保留原文给药途径和处理背景。系统注射、口服、细胞处理、人体外用探索结果均按实际终点解释，不自动升级为已证实化妆品功效。
9. **冲突**：保留相反和条件依赖结果，不给靶点永久固定“抗衰/促衰”属性。CGAS 2026 全身缺失、2013 与2021 SIRT6、IGF1R 队列差异、ATM 调节方向、RELA 不同缺失程度和 TP53 不同等位基因并列保留。
10. **文献**：元数据核实与提取结论核对分别标记。摘要可得时只提取摘要明确内容；检索片段、图注、选择性正文范围如实标注，不填写没有读到的剂量/时间/n。完整题名不做中文替代。
11. **更正**：检查可用关联更正/撤稿字段；逐出版商审计未完成时不得声称全面排除。BECN1 2018 Fig.2c 更正与 S6K1 2011 更正均可见；存在更正不等于撤稿。
12. **关系**：每条实验关系引用 evidence；背景关系引用明确来源。方向未知使用无箭头关系，颜色只作辅助。成员/主题归属不计实验因果边；数据库人工整理、人类事件、跨物种推断分别解释。
13. **路径**：不因共同文献、富集或共同通路补边；不由不同论文 A→B 与 B→C 宣称完整因果链。二层只称跨研究关联路径。
14. **统计**：节点大小、网络中心性、文献数不解释为抗衰效果或证据强度。不使用不透明可信度分数。
15. **维护**：稳定 ID，不静默覆盖已有修订；保留检索式、访问日期、纳入排除原因、版本和缺口。没有检索过的主题不能写“已检索无结果”。

分类以 [Cell 2023 框架](https://pubmed.ncbi.nlm.nih.gov/36599349/)为起点，允许扩展。结构检查只验证约束，不代替专家科学审核。

1.1.0 新增 ECM 扩展机制，`kind=extension` 与原12项 `kind=hallmark` 分开统计。ECM 为多组分环境，XVII 型胶原、I 型胶原及可溶胶原原料分别解释；基质硬度或黏附改变不具有跨模型一致的作用方向。

证据新增 `studyContext`：`aging_function` 为具明确衰老功能情境的实验，`nonaging_support` 为其他模型补充，`observational` 为观察关联。后两类可作为合格核心条目的补充，但不能单独满足核心依据，也不自动生成“衰老功能实验关系”。CCN1 在复制衰老中影响胶原稳态与在创面中促衰老限制纤维化并列保留。
